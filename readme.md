# PNG Asset Lab

Sprite sheet and PNG toolkit for [Acode](https://acode.app) on Android. Slice sprite sheets, preview animations, inspect pixels and alpha, scale PNGs, generate CSS and JSON metadata, export sprites (individually or as a ZIP), and browse image packs.

- Plugin ID: `com.rafi.png-asset-lab` | Version 1.0.0 | MIT | Author: Rafi (rafijordan4)
- Source: https://github.com/rafijordan4/png-asset-lab

## Install on Android (Acode)

1. Get `png-asset-lab-1.0.0-acode-plugin.zip` (from a GitHub Release or a CI artifact). **Do not** use the `...-dev-project.zip`.
2. Acode: **Settings > Plugins > + > LOCAL**, choose the ZIP.
3. Open the command palette and run **PNG Asset Lab: Open workspace**.

Remote install needs a *direct* ZIP URL, e.g. `https://github.com/rafijordan4/png-asset-lab/releases/download/v1.0.0/png-asset-lab-1.0.0-acode-plugin.zip`. A repository URL, an Actions artifact URL and a release page URL are all different things and will not work.

## Features

Workspace (import, zoom/pan/fit, checkerboard, pixel picker with RGBA/HEX, alpha inspection, nearest-neighbor, aspect-ratio scaling, PNG export) | Sprite sheet (columns/rows or sprite size, margins, spacing, overlay, coordinates, export one/all, empty-sprite detection) | Animation (frame sequence, FPS, loop, frame counter, backgrounds, frame export) | Code (CSS with real coordinates, JSON metadata, copy/save) | Image packs (8 bundled CC0 packs + Custom User Pack, import/export manifests, rename/remove with confirmation) | Light/dark theme, diagnostics.

PNG only. Maximum 16 megapixels / 8192 px per side / 32 MB per file.

## Where data lives

Persistent when `localStorage` works (Settings > Storage tells you): settings, recent file list, user packs and their images. Temporary: loaded image, selection, animation frames. Exports are written to the folder you choose and are never overwritten without asking.

## Licenses of bundled assets

All bundled packs, the sample sheet and the icon are original artwork generated by `scripts/gen-assets.py`, released under **CC0-1.0** (commercial use allowed, no attribution required). Each pack shows its license in the app. Packs you add yourself carry no license from this project.

## Build and test (Node 18+, no npm install needed)

```
node tests/run-tests.js      # manifest, syntax, assets, grid, CSS/JSON, ZIP writer, pack validation
node scripts/build.js        # writes dist/ (installable ZIP + dev ZIP)
node tests/validate-zip.js   # structure of the production ZIP
node tests/ui-smoke.js       # optional: real Chromium + MOCK Acode (needs Playwright)
python3 scripts/gen-assets.py && node scripts/gen-icons.js   # regenerate assets (needs Pillow)
```

Output: `dist/png-asset-lab-1.0.0-acode-plugin.zip` (install this) and `dist/png-asset-lab-1.0.0-dev-project.zip` (sources).

## Publish a release

Push a tag (`git tag v1.0.0 && git push --tags`), open the CI run, download the artifact, then create a GitHub Release and attach the production ZIP. The workflow only uploads an Actions artifact; it does not publish releases.

## Verified vs. not verified

Verified by automated checks: manifest, syntax, assets, grid math, CSS/JSON generation, filenames, in-app ZIP writer, pack validation, ZIP structure, and the full UI in headless Chromium against a **mock** Acode API.
**Not verified on a real Acode install (needs device testing):** `$page.show()/hide()` behaviour and Android back button, file browser and `fsOperation` writes of binary data (`createFile` with an ArrayBuffer, with a fallback), `localStorage` persistence inside Acode, clipboard, system file picker, drag and drop, performance on large images.

See `docs/troubleshooting.md`.
